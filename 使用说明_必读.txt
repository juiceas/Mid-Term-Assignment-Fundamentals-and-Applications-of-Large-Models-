快速开始（3步）
================================================================

第1步：安装依赖
-----------------
pip install torch numpy matplotlib tqdm pyyaml

或使用：
pip install -r requirements.txt

第2步：测试安装
-----------------
python test_model.py

如果看到"所有测试通过！"，说明安装成功。

第3步：开始训练
-----------------
选择以下方式之一：

方式1：快速演示（推荐，只需几分钟）
python quick_demo.py

方式2：完整训练
python src/train.py

方式3：使用脚本（Windows）
scripts\run.bat train

================================================================
常见问题
================================================================

Q: 如何修改超参数？
A: 编辑 src/train.py 中的 config 字典

Q: 训练需要多久？
A: quick_demo.py 约2-5分钟
   完整训练 约10-30分钟（取决于硬件）

Q: 内存不足怎么办？
A: 减小 batch_size、d_model、num_samples

Q: 如何使用自己的数据？
A: 修改 src/data_loader.py 中的数据加载函数

Q: 如何查看结果？
A: 查看 results/ 目录中的图表和JSON文件
